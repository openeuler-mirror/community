# ANSE SIG（AI-Native Software Engineering SIG）

sig-ANSE（AI原生软件工程SIG）基于 AI 原生软件工程范式， 为企业级软件交付提供可控、可靠、可演进的解决方案。

主要工作范围：

- **工具孵化**：基于AI原生的软件工程方法与理念，孵化和共建AI开发工具/框架。
- **评测基准**：制定面向基础软件的软件工程领域评测基准集并发布到openEuler社区。
- **规范与示例**：修订与发布openEuler社区AI辅助设计/编码/测试的规范与参考示例。
- **技术交流**：面向openEuler社区企业、高校与个人开发者，组织技术交流活动。

# 组织会议

- 会议时间：会议时间暂定为每双周周二上午，议题通过openEuler社区 <https://etherpad.openeuler.org/p/sig-ANSE-meetings> 进行申报
