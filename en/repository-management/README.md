# Repository Management

The openEuler project uses AtomGit to store and organize code, manage issues and documents, and provide a consistent contributor workflow. To simplify repository organization and management, we provide tools to automate management policies.

These policies and tools are supported by the platform management team under the Infrastructure SIG.
