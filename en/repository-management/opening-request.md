# How to Contact the Platform Management Team

If you need help with the following AtomGit-related topics, contact the platform management team:

- Permission issues
- Organization roles in the code hosting platform
- Third-party integration
- Repository creation and migration
- Repository archiving
- Other repository configuration issues

Submit an issue to [openEuler/infrastructure][infra-issues]. If your issue is urgent, contact a member of the platform management team directly.

To create a team, add members, or rename a team, follow the [team guide](./repository-management-guide.md) and submit a PR to [openEuler/technical-committee](../technical-committee/README.md).

## Community Bot and Automation Issues

If you need help with the following topics:

- Bot configuration
- Automatic merging
- Issue labels
- Automated feedback and feature requests

Submit an issue to [openEuler/infrastructure][infra-issues]. If your issue is urgent, contact a member of the platform management team directly.

[infra-issues]: https://atomgit.com/openeuler/infrastructure/issues
