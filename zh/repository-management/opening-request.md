# 如何向平台管理团队求助

如果你需要了解以下与 AtomGit 相关的内容，请向平台管理团队求助

- 权限问题
- 代码托管平台内的组织角色关系
- 第三方集成
- Repository的新建和迁移
- Repository的归档
- 其他repository配置相关的问题

请向[openEuler/infrastructure][infra-issues]提交你的issue。如果你的问题很紧急，请直接联系[平台管理团队的成员][infra-repo]。

创建新团队，添加新成员或者重命名您的团队，请根据[团队指南](./repository-management-guide.md)向[openEuler/technical-committee](../technical-committee/README.md)提交PR申请。



## 社区biot/自动化问题

如果您需要以下方面的帮助：

- biot配置
- 自动合并
- 问题标签
- 自动化反馈和功能需求

请向[openEuler/infrastructure][infra-issues]提交你的issue。如果你的问题很紧急，请直接联系[平台管理团队的成员][infra-repo]。

[infra-issues]: https://atomgit.com/openeuler/infrastructure/issues
[infra-repo]: https://atomgit.com/openeuler/infrastructure
